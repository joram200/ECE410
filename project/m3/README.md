# ECE 410 — Milestone 3: Option B Kalman Update Accelerator

## How to Reproduce

**Simulator:** Vivado xsim (via `xvlog` / `xelab` / `xsim`, non-project mode)
**Synthesis:** Vivado OOC non-project mode (`vivado -mode batch`)
**Target device:** Artix-7 100T (`xc7a100tcsg324-1`), 100 MHz

```bash
cd project/m3
bash run_m3.sh
```

Requires Vivado 2023.x or later in `PATH` (or set `VIVADO=<path>`).
GTKWave is optional; if not installed, `sim/cosim_waveform.vcd` is still generated
and can be opened manually to create `sim/cosim_waveform.png`.

## Design Summary

**Selected option:** Option B — Kalman update accelerator (`top`)
**Interface:** AXI4-Lite slave, 64-bit data, 32-bit address
**Compute core:** `kalman_update` (H=[1,0,0], R=5.0, Newton-Raphson reciprocal, 11-state FSM)
**Internal sub-core:** `gemm_systolic` (3x3 F64 weight-stationary array)
**Test stimulus:** 15-iteration Kalman filter sequence from RVfpgaEL2 profiling
**Verification:** AXI4-Lite protocol SVAs + FSM contract assertions + F64 ULP comparator (<=4 ULP)
