❯ Tell me how to run the files in scripts myself                                

● Here's how to run the scripts manually from the project root directory:

  Step 1 — Run the 15 profiling sessions (requires FPGA connected):
  bash scripts/run_profiles.sh
  This builds the firmware, starts OpenOCD, flashes and runs the firmware 15
  times via GDB, captures UART output, and extracts individual
  gmon_runs/gmon_1.out … gmon_15.out files.

  Step 2 — Combine and generate the report:
  bash scripts/combine_report.sh
  This merges all 15 .out files into gmon_runs/gmon.sum and generates:
  - gmon_runs/combined_report.txt — flat profile + call graph
  - gmon_runs/combined_report_annotated.txt — annotated source

  Prerequisites:
  - Run both from the project root (RVfpgaEL2_profiling/), not from inside
  scripts/
  - FPGA must be connected and /dev/ttyUSB1 must be available for
  run_profiles.sh
  - combine_report.sh can be run standalone if .out files already exist in
  gmon_runs/
